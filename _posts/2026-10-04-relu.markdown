The rectified linear unit is the least interesting function anyone could propose as a nonlinearity, and that is the whole point of it:

$$
f(x) = \max(0, x) , \qquad f'(x) = \begin{cases} 1 & x > 0 \\ 0 & x < 0 \end{cases} \tag{1}
$$

At the kink there is no derivative; implementations pick one from the subgradient $$[0, 1]$$ and nobody notices.

### What it fixes

Backpropagation multiplies one Jacobian per layer, so what matters about an activation is the factor it contributes. A sigmoid contributes $$\sigma'(z) = \sigma(1 - \sigma) \le 1/4$$, and $$1/4$$ is its *best* case, reached only at $$z = 0$$ — away from the origin it saturates and the factor collapses. Stack layers and the activation alone multiplies in at most $$(1/4)^L$$, which is about $$10^{-6}$$ by ten layers. That is the vanishing gradient, and it is not bad luck but the shape of the function.

ReLU contributes exactly $$1$$ wherever the unit is active. Not approximately, not on average — the derivative is the constant $$1$$ on the whole positive half-line, so an active path through the network attenuates not at all. The other half-line contributes $$0$$, which kills a unit rather than shrinking it, and that is a different problem.

### The idea

The spirit of ReLU is to cut the input space into many regions, be affine on each, and let the arrangement of the regions do the approximating.

That is the finite element method. Engineers have been approximating smooth physics with piecewise-linear elements on a mesh for sixty years, and everything carries over unchanged — the flat pieces, the refinement story, even the error law. One thing differs, and it is the whole of what deep learning added: a finite element mesh is laid out in advance by a person, whereas a network learns where to put its elements.

What follows does it twice. First by hand, fitting $$\sin x$$ with nothing but ReLUs; then in three dimensions, where the regions become facets and the thing being approximated is a surface.

### Building one by hand

To approximate $$\sin x$$ on $$[0, 2\pi]$$ with $$n$$ units:

1. **Pick the kinks.** Place $$b_1 < \dots < b_n$$ evenly across the interval.
2. **Read off the slope each segment needs.** Between consecutive kinks the polyline should join two points of the sine, so $$s_i = (\sin b_{i+1} - \sin b_i) / (b_{i+1} - b_i)$$.
3. **Turn slopes into weights.** A unit, once past its kink, stays on forever, so its only job is to change the slope permanently by $$a_i$$. That makes $$a_i = s_i - s_{i-1}$$ — this segment's slope minus the previous one's.

Taking $$s_0 = s_n = 0$$ leaves the network flat before the first kink and flat again after the last, and the whole thing is

$$
g(x) = \sum_{i=1}^{n} a_i \max(0, \, x - b_i) , \tag{2}
$$

with no bias and no second layer. It meets the sine exactly at every kink. Because the sine rises and then falls, the $$a_i$$ run negative through the first half, where each segment is less steep than the last, and positive through the second, where the slope climbs back.

(function(){
  var root = document.getElementById('relu-sine-demo');
  if (!root) return;
  var svg = root.querySelector('svg'),
      sl  = root.querySelector('.n'),
      eo  = root.querySelector('.err'),
      so  = root.querySelector('.seg'),
      no  = root.querySelector('.nv');
  var TAU = 2 * Math.PI;
  var L = 44, R = 630, T = 14, Bm = 272;
  var XA = -1.0, XB = TAU + 1.0, YA = -2.1, YB = 2.1;
  function fx(x){ return L + (x - XA) / (XB - XA) * (R - L); }
  function fy(y){ return Bm - (y - YA) / (YB - YA) * (Bm - T); }

  function build(n){
    var b = [], s = [], a = [], i, prev = 0, cur;
    for (i = 0; i < n; i++) b.push(TAU * i / (n - 1));
    for (i = 0; i < n - 1; i++) s.push((Math.sin(b[i+1]) - Math.sin(b[i])) / (b[i+1] - b[i]));
    for (i = 0; i < n; i++){ cur = (i < n - 1) ? s[i] : 0; a.push(cur - prev); prev = cur; }
    return { b: b, a: a };
  }
  function partial(x, k, p){
    var y = 0, t, i;
    for (i = 0; i < k; i++){ t = x - p.b[i]; if (t > 0) y += p.a[i] * t; }
    return y;
  }
  function g(x, p){
    var y = 0, t, i;
    for (i = 0; i < p.b.length; i++){ t = x - p.b[i]; if (t > 0) y += p.a[i] * t; }
    return y;
  }
  function pts(arr){ return arr.map(function(q){ return fx(q[0]).toFixed(1) + ',' + fy(q[1]).toFixed(1); }).join(' '); }

  function draw(){
    var n = +sl.value, p = build(n), i, j, x, k, vs, xe, out = [];

    var worst = 0, N = 2000;
    for (k = 0; k <= N; k++){ x = TAU * k / N; worst = Math.max(worst, Math.abs(Math.sin(x) - g(x, p))); }
    no.textContent = n; so.textContent = n - 1; eo.textContent = worst.toFixed(3);

    [-1, 0, 1].forEach(function(v){
      out.push('<line x1="' + L + '" y1="' + fy(v).toFixed(1) + '" x2="' + R + '" y2="' + fy(v).toFixed(1) +
               '" stroke="currentColor" stroke-opacity="' + (v === 0 ? 0.3 : 0.14) + '" stroke-width="1"/>');
      out.push('<text x="' + (L - 8) + '" y="' + (fy(v) + 4).toFixed(1) +
               '" text-anchor="end" font-size="11" fill="currentColor" fill-opacity="0.6">' + v + '</text>');
    });
    [[0, '0'], [Math.PI, 'π'], [TAU, '2π']].forEach(function(t){
      out.push('<text x="' + fx(t[0]).toFixed(1) + '" y="' + (Bm + 18) +
               '" text-anchor="middle" font-size="11" fill="currentColor" fill-opacity="0.6">' + t[1] + '</text>');
    });

    for (k = 1; k < n; k++){
      vs = [[XA, 0]];
      for (j = 0; j < k; j++) vs.push([p.b[j], partial(p.b[j], k, p)]);
      xe = Math.min(XB, p.b[k] + 1.3);
      vs.push([xe, partial(xe, k, p)]);
      out.push('<polyline points="' + pts(vs) +
               '" fill="none" stroke="currentColor" stroke-opacity="0.3" stroke-width="1"/>');
    }

    var sine = [];
    for (k = 0; k <= 180; k++){ x = XA + (XB - XA) * k / 180; sine.push([x, Math.sin(x)]); }
    out.push('<polyline points="' + pts(sine) + '" fill="none" stroke="currentColor" stroke-opacity="0.55" stroke-width="1.6" stroke-dasharray="6 5"/>');

    var net = [[XA, g(XA, p)]];
    for (i = 0; i < n; i++) net.push([p.b[i], g(p.b[i], p)]);
    net.push([XB, g(XB, p)]);
    out.push('<polyline points="' + pts(net) + '" fill="none" stroke="#3b82f6" stroke-width="2.2"/>');

    if (n <= 24){
      for (i = 0; i < n; i++){
        out.push('<circle cx="' + fx(p.b[i]).toFixed(1) + '" cy="' + fy(g(p.b[i], p)).toFixed(1) +
                 '" r="3.4" fill="#3b82f6"/>');
      }
    }
    svg.innerHTML = out.join('');
  }

  sl.addEventListener('input', draw);
  draw();
})();

### The same trick as a triangle mesh

This is what 3D modelling has always done. A sphere in a renderer is not a sphere; it is a few thousand flat triangles. Every facet is flat, every normal within a facet is constant, and all of the shape lives in how the facets are arranged. Refine the mesh and you converge on the surface, and at no point does anything actually curve.
